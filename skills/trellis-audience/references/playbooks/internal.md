# Playbook: internal
Ladder maps to commitment, not reach: L3 a named sponsor agrees a pilot · L4 sponsor commits budget or
headcount in writing · L5 a user group completes the outcome via the manual/concierge process.
Audience track: A1 = sponsor and user group identified; A2 = a channel to the user group (team
channel, mailing list); A3 = first participation test (will the user group attend a walkthrough?).
Cold start: not applicable; the audience is given. Credibility = sponsor authority.
Compliance: internal data policies; classified fields apply.
Benchmark sources: none external; thresholds are unbenchmarked from the start and set against the
cost of the manual process the tool replaces.
