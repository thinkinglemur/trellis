# Playbook: developer
Ladder: L1 repo star / docs visit · L2 email or waitlist · L3 `npm install`/`pip install` against a
working stub, or an issue opened · L4 paid tier pre-order or sponsored seat · L5 paid integration done
with them (Stripe-style "install it for them").
Channel map: founder channel = X or Bluesky and GitHub presence; rooms = language/framework Discords,
Hacker News (no self-promo), dev subreddits, Stack Overflow; marketplaces = npm/PyPI/plugin registries.
Cold start: open-source something useful; registry listing; answer questions in rooms; targeted
outreach to maintainers; docs that rank for the actor's search.
Compliance: B2B legitimate interest; developer rooms punish promotion — participation first.
Benchmark sources: registry download statistics, OSS adoption write-ups, developer-tool conversion
reports (OpenView, a16z dev-tools posts) — note that free-to-paid conversion varies by an order of
magnitude across categories.
