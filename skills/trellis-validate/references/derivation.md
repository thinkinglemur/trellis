# Deriving growth artefacts from the PDD (ODG §4) — mechanical; owner ratifies
POSITIONING.md  ← MVP.md value hypothesis: "If <actor> can <outcome>, then <signal>" →
                  "For <actor> who needs <outcome>, <product> does <X>." One sentence. No new claims.
ICP             ← PDD §2 actors: one profile per human actor + eligibility preconditions from use cases.
MESSAGING.md    ← outcome descriptors with a passing e2e test (or, pre-build, a passing walkthrough
                  record) — one benefit claim per outcome. Untraced claim → not permitted.
Trust messaging ← abuse cases (AC-nnn) and classified fields: concrete refusals/protections only.
Activation      ← first `UC-anchor.completed` per actor.   Retention ← repeat, by weekly cohort.
Onboarding      ← first-run archetype → anchor outcome; step count ≤ PDD.
Launch scope    ← MVP.md.   Channel hypotheses ← actors (see trellis-audience).
Rule: if the owner wants a claim that has no outcome, the route is a use case → outcome → test, not copy.
